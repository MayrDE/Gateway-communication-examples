# Get RBC CycleData

Gets the last recorded cycle data values.

## Required service level

`none`

## Command

**REST-API**  
Request:

```bash
GET {BaseURL}/RBC/CycleData
```

Body: none

---

**MQTT**  
No request necessary, cylce data is published automatically on complete cycle

---

**WebSocket**  
No request necessary, cylce data is sent automatically on complete cycle
