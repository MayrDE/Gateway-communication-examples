# Gateway Toslink Settings Response

Provides the Toslink settings of the gateway.

## Parameters

For detailed description of the parameters see [Set Gateway Toslink Settings](Gateway_Set_ToslinkSettings.md#parameters).

## REST-API

Response:

```bash
http Header with status code 200 OK
```

Body (example):  
type: JSON Object

```json
{
    "Toslink": {
        "Enabled": true
    }
}
```
