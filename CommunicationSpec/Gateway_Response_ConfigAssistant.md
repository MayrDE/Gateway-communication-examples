# Gateway Config Assistant Response

Provides the current status of the configuration assistant ON or OFF.

## Parameters

For detailed description of the parameters see [Set Gateway ConfigAssistant](Gateway_Set_ConfigAssistant.md#parameters).

## REST-API

Response:

```bash
http Header with status code 200 OK
```

Body (example):
type: JSON Object

```json
{
    "Value": true
}
```
